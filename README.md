# geo-mock — 讓瀏覽器假裝你在別的地方

指定一組 GPS 座標，**網站問你在哪裡的時候，瀏覽器就回報你指定的那組座標**，
而不是你真正的位置。

用來做什麼：

- 你做的網站會依使用者所在縣市顯示不同內容，想在自己電腦上看看台南的使用者會看到什麼
- 外送、地圖、找門市這類功能，想測「使用者在很遠的地方」時畫面長怎樣
- 想確認網站在拿不到位置、或位置一直微幅飄動時會不會出錯

> **這是開發／測試工具。** 它只影響你自己這台電腦的瀏覽器，不會讓你「真的」出現在別的地方。

---

## 兩種用法，挑一個

| | **Simulator**（`simulator/`） | **擴充功能**（`extension/`） |
|---|---|---|
| 怎麼運作 | Python 程式起一個專用的 Chrome，用 Chrome 官方的偵錯協定改掉定位 | 裝進你日常的 Chrome，在網頁裡換掉定位功能 |
| 用哪個瀏覽器 | 它自己開的那個視窗（沒登入 Google） | 你平常在用的那個 |
| 網站看得穿嗎 | 看不穿，也繞不過 | **看得穿，也繞得過** |
| 會自己驗證嗎 | 會，跑完直接告訴你 PASS / FAIL | 不會，要自己看 |
| 有沒有圖形介面 | 有（PySide6），也有 CLI | 有（瀏覽器工具列的面板） |
| 適合 | 要**確定**真的生效（例如 Google Maps 的藍點） | 平常隨手切座標、多個分頁一起用 |

兩個是獨立的，不互相依賴。

## Simulator 快速上手

需要 [uv](https://docs.astral.sh/uv/)（Python 的套件管理器）與 Google Chrome。

```bash
cd simulator
uv sync

# 看看這台電腦支援哪些做法
uv run python -m gpssim.cli detect

# 開始模擬並實際驗證（會開一個 Chrome 視窗）
uv run python -m gpssim.cli maps --coords "25.033964, 121.564468"
```

跑完會印出這樣的結果，**三項都 PASS 才算真的成功**：

```
Platform:                    Darwin 14.6.1 (arm64)
Browser:                     Google Chrome 152.0.7977.65
Location Simulation Method:  CDP Emulation.setGeolocationOverride
Supported:                   YES

navigator.geolocation:       PASS  (0.00 m)
Google Maps (geolocation):   PASS  (0.00 m)
Google Maps (Your Location): PASS  (0.00 m)
```

它還會把 Google Maps 的截圖存到 `.screenshots/`，可以直接看藍點在不在正確位置。

### 圖形介面

不想打指令的話有 GUI：

```bash
uv sync --extra gui
uv run python -m gpssim.cli gui
```

填緯度經度（也可以直接把「25.033964, 121.564468」整串貼進緯度欄，會自動拆成兩欄），
按「開始模擬」。它會開一個 Chrome、跑完驗證、把結果印在下面，然後**保持那個瀏覽器開著**
讓你自己操作。按「停止模擬」或關掉視窗就會收掉瀏覽器並還原。

### 讓它開著自己操作（CLI）

想讓瀏覽器一直開著自己操作，用 `start` 代替 `maps`：

```bash
uv run python -m gpssim.cli start --coords "25.033964, 121.564468" --maps
```

按 Enter 就會停止模擬並關掉那個 Chrome。

**注意**：它一定會自己開一個新的 Chrome，不能接管你正在用的那個 ——
Chrome 136 之後為了保護日常 profile 的資料，禁止對預設 profile 開偵錯連線。
所以那個視窗沒有登入你的 Google 帳號。

其他指令與踩過的雷見 [`simulator/CLAUDE.md`](simulator/CLAUDE.md)。

# 擴充功能

以下是**擴充功能**的說明。想用 Simulator 的話上面那段就夠了。

裝上之後，你可以指定一組 GPS 座標，所有網站問你在哪裡的時候，瀏覽器都會回報你指定的那組座標。
它不綁定特定網站，對任何網站都有效。

> 不適合拿來規避網站的地區限制 —— 會認真檢查的網站有辦法看穿它（見最後的「它的極限」）。

---

## 開始之前


- 需要 **Chrome 111 或更新的版本**。不確定的話開 Chrome 選單 →「說明」→「關於 Google Chrome」看得到版本號
- 不需要註冊帳號、不需要任何金鑰

## 安裝

這個擴充沒有上架到 Chrome 線上應用程式商店，所以是用「開發人員模式」直接載入資料夾。聽起來嚇人，其實就是四個步驟。

### 1. 把檔案抓到電腦上

有兩種方式，任選一種：

- 對方給你一個 zip 檔 → 解壓縮，記住資料夾放在哪
- 或你自己用 git：

  ```bash
  git clone git@github.com:kopp0510/geo-mock.git
  ```

解開後，擴充功能的檔案在 **`extension/` 這個子資料夾**裡，裡面看得到 `manifest.json`。
**等一下要選的就是 `extension/` 這一層，不是最外層的 `geo-mock/`** —— 這是最常選錯的地方。

### 2. 打開 Chrome 的擴充功能頁

在網址列輸入這行，按 Enter：

```
chrome://extensions
```

（這是 Chrome 的內建頁面，不是網站，Google 搜尋不到。）

### 3. 打開右上角的「開發人員模式」

那個頁面的**右上角**有一個「開發人員模式」的開關，把它打開。打開後，左上角會多出三顆按鈕。

### 4. 載入資料夾

點左上角的「**載入未封裝項目**」，選第 1 步那個資料夾裡的 **`extension/`**（包含 `manifest.json` 的那一層），按「選取」。

成功的話，頁面上會出現一張 geo-mock 的卡片，而且你的 Chrome 工具列（網址列右邊）會多一個圖示。

> 找不到圖示的話，點工具列上那個拼圖形狀的按鈕，在清單裡找到 geo-mock，按旁邊的圖釘把它固定出來。

## 第一次使用

**裝好的當下它就已經在運作了**，預設回報的座標是台北 101 附近。

試一下：

1. 點工具列上的 geo-mock 圖示，會跳出一個小面板
2. 在最上面的搜尋框打「**台南火車站**」，**按 Enter**（打字不會自動搜尋，要按 Enter 或旁邊的「搜尋」鈕）
3. 下面會出現幾個候選地址，點你要的那一個
4. 面板中間的「緯度／經度」會換成新的座標

現在去任何一個會問你位置的網站，它拿到的就是台南火車站的座標了。

### 怎麼確認真的生效了

專案裡附了一個測試頁，**它只問瀏覽器位置、完全不查 IP**，所以看到什麼就是網站實際拿到的座標，不會有「到底是擴充生效還是它在猜」的疑問。

在專案資料夾裡開終端機，執行：

```bash
python3 -m http.server 8000 -d tools/fixtures
```

然後瀏覽器開 <http://localhost:8000/test.html>。頁面上會直接顯示座標。改完設定後按頁面上的「重新定位」再問一次。

> 網路上那些「查詢我的位置」的測試網站多半混用 IP 位置，測出來分不清是哪個在作用，不建議拿來驗這個擴充。

## 各項功能

點工具列圖示打開的那個小面板，由上到下：

### 右上角的開關

總開關。關掉之後所有網站都拿到你的真實位置。

### 地址搜尋

打地址或地標，**按 Enter**（或旁邊的「搜尋」鈕），下面出現候選清單，點一下就套用。

**為什麼不是打字就自動搜尋**：地址資料來自 OpenStreetMap 的免費服務，它的使用規則明文禁止「邊打邊查」這種用法，違反會被封鎖。查過的地址會記在本機，重複查同一個不會再連線。

### 模式：固定 / 抖動

- **固定** —— 就回報你設定的那一組座標，每次都一樣
- **抖動** —— 以你設定的座標為中心，每次問都在附近隨機取一點

抖動是用來看「座標一直微幅跳動時，你的網站會不會出錯」—— 例如地圖上的圖釘一直抖、或是重複觸發「你進入了某區域」的判定。範圍多大在「進階設定」裡調（預設 50 公尺）。

要完全關掉就用右上角的開關，模式裡沒有「關閉」這個選項。

### 已存地點

按「**＋ 存目前座標**」，給它取個名字（例如「公司」），之後點那個小標籤就切回去。按標籤上的 × 可以刪掉。最多存 12 個。

### 這個網站不要覆寫

有些網站你不想被影響 —— 網銀、訂票、你真的要用的地圖。在那個網站上點開面板，按「**這個網站不要覆寫**」，它就會拿到你的真實位置，其他網站不受影響。再按一次可以恢復。

清單可以在「進階設定」裡看到跟編輯，也能手動加（支援 `localhost:3000` 這種帶埠號的，以及 `*.example.com` 這種涵蓋所有子網域的寫法）。

### 語言

面板最下面可以切繁體中文／English／跟隨瀏覽器，選了立刻換。

### 進階設定

點面板最下面的「進階設定」會開一個新分頁，可以直接填經緯度、accuracy（回報給網站的「誤差半徑」）、抖動半徑，也能編輯排除清單。

最上面有一個「**貼上座標**」欄很好用：在 Google Maps 上對著任何位置按右鍵，第一行就是「25.033, 121.5654」這種座標，複製整串直接貼進去，它會自動拆進下面兩欄。

## 遇到問題

### 改了設定，網站上卻沒變

**設定是即時生效的，不必重新整理分頁** —— 但網站要**再問一次位置**才會拿到新座標。已經在載入時抓好位置、存起來用的頁面不會自己更新。

按網站上的「重新定位」「重新整理位置」之類的按鈕，或直接重新整理那個分頁。

### 剛更新完程式碼，即時生效失靈了

如果你在 `chrome://extensions` 按了那張卡片上的「重新載入」，**已經開著的分頁需要重新整理一次**才會恢復。

這是 Chrome 的行為：它不會把擴充的程式碼重新塞進已經開著的分頁，只會把舊的那份切斷。不知道這件事的話，會以為即時生效壞掉了。

### 每次開 Chrome 都跳出「停用開發人員模式擴充功能」

按「取消」就好，這是 Chrome 對所有「載入未封裝項目」的擴充都會做的提醒，不是這個擴充有問題。

### 網站好像完全沒問我位置

有些網站會先確認「使用者給權限了嗎」，看到「還沒決定」就乾脆不問了。這個擴充會回答「已經給了」來避免這種情況。如果還是沒動靜，先確認右上角的開關是開的、而且這個網站沒有被加進排除清單 —— 被排除的話，面板上會直接顯示「這個網站已排除，走真實定位」。

### 我忘了關，每個網站都拿到假座標

這是預設行為 —— 裝上就生效，對所有網站。不用時記得用右上角的開關關掉。

覆寫生效時，那個網頁的開發人員工具 Console 會印一行 `[geo-mock] 定位已覆寫為 …`，那是唯一的痕跡。（Console 的打開方式：在網頁上按右鍵 →「檢查」→ 選上面的「Console」分頁。）

## 它會存什麼、送出什麼

**存在你電腦上**（Chrome 的擴充儲存空間，不會上傳）：

- 你設定的座標、模式、抖動半徑、語言、開關狀態
- 你存的地點名稱與座標
- 你排除的網站清單
- 搜尋過的地址與結果（快取 7 天，避免重複連線）

**會離開你電腦的只有一件事**：你在搜尋框打的地址字串，會送給 OpenStreetMap 的地址查詢服務。不會送出你的座標、不會送出你的身分、也不會送出上面那些清單。

不搜尋地址的話，這個擴充完全不連外網。

## 它的極限

這個擴充是在網頁的 JavaScript 環境裡「換掉」瀏覽器的定位功能。這決定了兩件事：

- **會認真檢查的網站看得出來**，也有辦法繞過它拿到真實位置。它擋不住反詐欺、反作弊那類系統
- 它回報的位置**不是真的** —— 網站看到的 IP 位址、時區、語言設定都還是你原本的，只有座標被換掉

拿來開發測試很好用，拿來假裝自己在別的國家不會成功。

## 給要改程式的人

```bash
node tools/verify.js                                                # 擴充：exit 0 = 十四項斷言全過
cd simulator && uv run python -m gpssim.cli maps --coords "25.0,121.5"   # Simulator：三項全 PASS
```

需要 playwright 與 Chrome for Testing（**系統的 Chrome stable 不行**，151 起已忽略 `--load-extension`，而且不會有任何錯誤訊息）。細節見 [tools/CLAUDE.md](tools/CLAUDE.md)。

擴充在技術上是 Manifest V3、純原生 JS，沒有 build 工具也沒有相依套件（Simulator 是 Python + `uv`，兩層的技術棧刻意不同）。地址搜尋用 [Nominatim](https://nominatim.openstreetmap.org/)，資料來源 © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors；它的[使用政策](https://operations.osmfoundation.org/policies/nominatim/)是硬約束（每秒至多 1 次、必須快取、必須以可識別的 User-Agent 送出、必須標示出處、不得實作打字即查），相關程式碼集中在 `extension/geocode.js`、`extension/rules.json` 與 `extension/background.js`。

**要給不特定公眾使用（上架）之前必須換掉地址搜尋服務** —— 那條政策的每秒 1 次是「所有使用者流量的總和」，而且要求能在對方要求時不透過版本更新就切換服務。
